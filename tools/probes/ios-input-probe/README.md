# MASAR Input Probe (iPadOS)

A small native SwiftUI diagnostic app. It answers Phase 0's highest-risk question with evidence from the real device:

> When a Logitech G923 (PlayStation version) is plugged into the iPad Pro M5, what does iPadOS expose to a third-party app through public APIs?

## What it reports

| Area | API used | Notes |
|---|---|---|
| Connected controllers | `GCController.controllers()` + connect/disconnect notifications | Vendor name, product category, profile type |
| Every input element | `GCController.physicalInputProfile.elements` | Live value plus **min/max seen**, so you can check full wheel rotation and pedal travel |
| Haptics | `GCController.haptics` → `CHHapticEngine` | The test button only plays through an engine the OS returns. The result is logged truthfully |
| Racing-wheel API | `NSClassFromString("GCRacingWheel")` | Reports whether the class exists on this OS build |
| Keyboard / mouse | `GCKeyboard`, `GCMouse` | Some USB devices show up as these |
| Thermal | `ProcessInfo.thermalState` + change notification | |
| Memory | `os_proc_available_memory()`, `task_vm_info.phys_footprint`, `physicalMemory` | |
| GPU | `MTLCreateSystemDefaultDevice()` | Families, ray tracing support, recommended working set |

**Limitation:** an iPadOS app **cannot** list raw USB/HID devices. If the G923 isn't exposed through the GameController framework, this probe will show "no controllers". That itself is the evidence. Raw access would need DriverKit (see `docs/research/PHASE0_RESEARCH.md`).

## Build

You can't build this on Windows. CI builds it on a GitHub-hosted macOS runner:

- Workflow: `.github/workflows/ios-input-probe.yml`
- The project file is generated by **XcodeGen** from `project.yml`, so there's no hand-edited `.xcodeproj`
- Output: `MasarInputProbe-unsigned.ipa` (an artifact)

For signing and installation options, see `BUILD_INSTRUCTIONS.md` at the repository root.

## Test procedure on the iPad

1. Install and open the app. Leave it in the foreground.
2. Plug in the G923 through the USB-C adapter. Note whether a CONNECT event appears.
3. Turn the wheel fully left, then fully right. Press each pedal fully. Press every button and the D-pad.
4. Tap **Test haptics** if a haptics engine is listed.
5. Unplug and re-plug once to test reconnection.
6. Tap **Share report** and send the text back. It goes into `PERFORMANCE_REPORT.md` and `KNOWN_ISSUES.md`.
7. For comparison, repeat with a PlayStation or Xbox controller if you have one. This proves the probe itself works.
